GREY REPAIRS — DESIGN UPDATE

This version updates the visual theme to a navy-blue and white palette:
- Page background: #F4F6F9
- Header / deep navy: #172554
- Primary button blue: #1D4ED8
- Hover blue: #1E40AF
- Light blue accent: #EFF6FF

It also adds clearer keyboard focus indicators, reduced-motion support, and a few mobile interaction refinements.

Installation:
1. Back up your current electronics-repair folder.
2. Extract this archive.
3. Copy the included electronics-repair/style.css over your existing style.css.
4. Refresh the browser with Ctrl+F5.

This package does not replace or migrate your database. Test all existing PHP workflows locally after applying the CSS update.
